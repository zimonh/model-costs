About tokens

What is a token?

Language models read and write text in tokens: common words are one token, rarer words are split into pieces. In English a token is about 4 characters, or three quarters of a word. API prices are per token.

How many tokens is 1,000 words?

About 1,300 tokens for English text with OpenAI's tokenizer. Code, numbers and other languages use more tokens per word.

Does this count tokens like ChatGPT does?

Yes. It uses o200k_base, the tokenizer of GPT-4o and newer OpenAI models, so the count is exact for them. Claude, Gemini and other models use their own tokenizers, so for those it is a close estimate.

Is my text uploaded?

No. The tokenizer runs in your browser; the text never leaves your device.

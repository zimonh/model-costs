    FAQ

    How much does the ChatGPT API cost?

    The ChatGPT (OpenAI) API is billed per token, with separate prices for input and output tokens. Prices range from a few cents per million tokens for the smallest models to tens of dollars for the largest. A token is roughly 4 characters of English text. Paste your prompt into the calculator to see the exact cost per request.

    Is the API included in ChatGPT Plus?

    No. A ChatGPT Plus or Pro subscription covers the ChatGPT app only. The OpenAI API is billed separately, pay as you go, through the OpenAI platform.

    How is the API cost calculated?

    Cost = input tokens × input price + output tokens × output price. Prices are per 1 million tokens, in US dollars. Multiply by the number of requests to get the total.

    How often are the prices updated?

    Every day. Prices come from the open LiteLLM price list, which links each provider's official pricing page. Each model links to its source.

    What is batch pricing?

    OpenAI, Anthropic and Google offer a batch API: you send requests that are processed within 24 hours, at about half the normal price. Models without a batch price show a dash.

    What is cached input?

    When the start of a prompt repeats across requests, providers can cache it and charge a much lower rate for those tokens, often 10% of the normal input price. Turn on "Cached input" to price the whole prompt at that rate.

    Are the token counts exact?

    Token counts use OpenAI's o200k tokenizer, the one GPT-4o and newer OpenAI models use, so they are exact for those models. Claude, Gemini and other models count tokens differently, so treat those as close estimates. You can also type a token count yourself.

    Is my text sent anywhere?

    No. Everything runs in your browser. The page only downloads the price list. If you allow analytics, Google Analytics counts which model you pick and the rounded size of a calculation, never your text. See privacy.

Questions and answers

How much does the Gemini 3.8 Flash API cost?

Google Gemini charges $0.75 per million input tokens and $3.75 per million output tokens for Gemini 3.8 Flash (gemini-3.8-flash), and $0.075 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.00263, or $0.00131 through the batch API.

Is there a cheaper way to use Gemini 3.8 Flash?

Yes. The Google Gemini batch API runs requests within 24 hours for $0.375 per million input tokens and $1.875 per million output tokens. Prompt caching lowers the price of repeated input to $0.075 per million tokens.

What is the context window of Gemini 3.8 Flash?

Gemini 3.8 Flash accepts up to 1,048,576 input tokens, roughly 786,000 words of English, and writes up to 65,536 output tokens per response. Filling the whole context window once costs $0.79 in input tokens.

Is Gemini 3.8 Flash cheaper than GPT-5.4 mini?

Yes. GPT-5.4 mini from OpenAI costs $0.75 input and $4.5 output per million tokens, so a typical request is $0.003: 1.1× the price of Gemini 3.8 Flash.

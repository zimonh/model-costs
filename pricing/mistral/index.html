Mistral API pricing

As of October 28, 2026, the Mistral API costs $0.1 to $1.5 per million input tokens and $0.1 to $7.5 per million output tokens, across 16 Mistral models. Ministral 3 3B 2512 costs $0.1 input and $0.1 output; Ministral 3 8B 2512 costs $0.15 input and $0.15 output; Mistral Small costs $0.1 input and $0.3 output; Ministral 3 14B 2512 costs $0.2 input and $0.2 output; Mistral Tiny costs $0.25 input and $0.25 output; Open Mistral Nemo costs $0.3 input and $0.3 output; Codestral 2508 costs $0.3 input and $0.9 output; DeepSeek V4 1 Flash 1017 costs $0.3 input and $1.2 output. A typical request of 1,000 input and 500 output tokens costs $0.00015 on Ministral 3 3B 2512 and $0.00525 on Mistral Medium.

How batch, prompt caching and long context change the price

Batch API. The price list has no batch API prices for Mistral models. See batch API pricing.

Prompt caching. All 15 priced Mistral models charge less for cached input, the part of a prompt that repeats across requests: typically 90% less. DeepSeek V4 1 Flash 1017 charges $0.007 per million cached input tokens instead of $0.3. See prompt caching pricing.

Long context. Mistral models accept 32K to 1.05M input tokens. The price list shows no long-context surcharge for Mistral: each model has one price up to its full context window. Filling a 1M-token window is still expensive, though: the input alone costs $0.30 on DeepSeek V4 1 Flash 1017.

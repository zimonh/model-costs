Questions and answers

How much does the GPT-5.5 API cost?

OpenAI charges $5 per million input tokens and $30 per million output tokens for GPT-5.5 (gpt-5.5), and $0.5 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.02, or $0.01 through the batch API.

Is there a cheaper way to use GPT-5.5?

Yes. The OpenAI batch API runs requests within 24 hours for $2.5 per million input tokens and $15 per million output tokens. Prompt caching lowers the price of repeated input to $0.5 per million tokens.

What is the context window of GPT-5.5?

GPT-5.5 accepts up to 1,050,000 input tokens, roughly 788,000 words of English, and writes up to 128,000 output tokens per response. Filling the whole context window once costs $5.25 in input tokens.

Is GPT-5.5 cheaper than Claude Opus 4.5?

No. Claude Opus 4.5 from Anthropic costs $5 input and $25 output per million tokens, so a typical request is $0.0175: 1.1× cheaper than GPT-5.5.

gemini-2.5-flash API pricing

Google Gemini charges $0.3 per million input tokens and $2.5 per million output tokens for gemini-2.5-flash, and $0.03 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.00155, or $0.000775 through the batch API.

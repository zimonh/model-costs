gpt-4o API pricing

OpenAI charges $2.5 per million input tokens and $10 per million output tokens for gpt-4o, and $1.25 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.0075, or $0.00375 through the batch API.

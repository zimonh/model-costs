Questions and answers

How much does the Claude Sonnet 5 API cost?

Anthropic charges $2 per million input tokens and $10 per million output tokens for Claude Sonnet 5 (claude-sonnet-5), and $0.2 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.007, or $0.0035 through the batch API.

Is there a cheaper way to use Claude Sonnet 5?

Yes. The Anthropic batch API runs requests within 24 hours for $1 per million input tokens and $5 per million output tokens. Prompt caching lowers the price of repeated input to $0.2 per million tokens.

What is the context window of Claude Sonnet 5?

Claude Sonnet 5 accepts up to 1,000,000 input tokens, roughly 750,000 words of English, and writes up to 128,000 output tokens per response. Filling the whole context window once costs $2.00 in input tokens.

Is Claude Sonnet 5 cheaper than GPT-6 Sol?

They cost about the same. GPT-6 Sol from OpenAI costs $2 input and $10 output per million tokens, so a typical request is $0.007: about the same price as Claude Sonnet 5.

Questions and answers

How much does the DeepSeek Coder API cost?

DeepSeek charges $0.14 per million input tokens and $0.28 per million output tokens for DeepSeek Coder (deepseek-coder), and $0.014 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.00028.

Is there a cheaper way to use DeepSeek Coder?

Prompt caching lowers the price of input that repeats across requests to $0.014 per million tokens.

What is the context window of DeepSeek Coder?

DeepSeek Coder accepts up to 128,000 input tokens, roughly 96,000 words of English, and writes up to 4,096 output tokens per response. Filling the whole context window once costs $0.0179 in input tokens.

Is DeepSeek Coder cheaper than GPT-5 nano?

No. GPT-5 nano from OpenAI costs $0.05 input and $0.4 output per million tokens, so a typical request is $0.00025: 1.1× cheaper than DeepSeek Coder.

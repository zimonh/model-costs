DeepSeek API pricing

As of October 28, 2026, the DeepSeek API costs $0.14 to $1.32 per million input tokens and $0.28 to $3.96 per million output tokens, across 7 DeepSeek models. DeepSeek Coder costs $0.14 input and $0.28 output; DeepSeek V3.2 costs $0.28 input and $0.4 output; DeepSeek V3 costs $0.27 input and $1.1 output; DeepSeek Flash costs $0.3 input and $1.2 output; DeepSeek V4 Flash costs $0.3 input and $1.2 output; DeepSeek R1 costs $0.55 input and $2.19 output; DeepSeek V4 Pro costs $1.32 input and $3.96 output. A typical request of 1,000 input and 500 output tokens costs $0.00028 on DeepSeek Coder and $0.0033 on DeepSeek V4 Pro.

How batch, prompt caching and long context change the price

Batch API. The price list has no batch API prices for DeepSeek models. See batch API pricing.

Prompt caching. All 7 priced DeepSeek models charge less for cached input, the part of a prompt that repeats across requests: typically 90% less. DeepSeek V4 Pro charges $0.044 per million cached input tokens instead of $1.32. See prompt caching pricing.

Long context. DeepSeek models accept 65.5K to 1M input tokens. The price list shows no long-context surcharge for DeepSeek: each model has one price up to its full context window. Filling a 1M-token window is still expensive, though: the input alone costs $1.32 on DeepSeek V4 Pro.

It depends on the model. The cheapest DeepSeek model, DeepSeek Coder, costs $0.00028 per typical request; the cheapest OpenAI model, GPT-5 nano, costs $0.00025. DeepSeek V4 Pro ($0.0033) is closest in price to GPT-6.1 Terra ($0.0035): about the same.

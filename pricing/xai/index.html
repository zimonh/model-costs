Grok API pricing (xAI)

As of October 28, 2026, the Grok API costs $1 to $2 per million input tokens and $2 to $6 per million output tokens, across 7 Grok models. Grok Build 0.1 costs $1 input and $2 output; Grok Code Fast costs $1 input and $2 output; Grok 4.7 costs $2 input and $6 output. A typical request of 1,000 input and 500 output tokens costs $0.002 on Grok Build 0.1 and $0.005 on Grok 4.7.

How much does a Grok API request cost?

A typical request of 1,000 input and 500 output tokens costs $0.002 on Grok Build 0.1, $0.002 on Grok Code Fast and $0.005 on Grok 4.7. A coding agent step with 50K tokens of context and 2K output tokens costs $0.11 on Grok 4.7.

How batch, prompt caching and long context change the price

Batch API. 3 of the 7 priced Grok models have a batch API price. Requests sent as a batch are processed within 24 hours and cost 20% less: Grok 4.7 drops from $2 input and $6 output to $1.6 and $4.8 per million tokens. See batch API pricing.

Prompt caching. All 7 priced Grok models charge less for cached input, the part of a prompt that repeats across requests: typically 80% less. Grok 4.7 charges $0.5 per million cached input tokens instead of $2. See prompt caching pricing.

Long context. Grok models accept 256K to 1M input tokens. Long prompts cost more on 7 models: Grok Build 0.1 charges $2 input and $4 output per million tokens once a prompt is over 200K tokens, instead of $1 input and $2 output; Grok Code Fast charges $2 input and $4 output per million tokens once a prompt is over 200K tokens, instead of $1 input and $2 output; Grok 4.3 charges $2.5 input and $5 output per million tokens once a prompt is over 200K tokens, instead of $1.25 input and $2.5 output; Grok 4.20 charges $2.5 input and $5 output per million tokens once a prompt is over 200K tokens, instead of $1.25 input and $2.5 output; Grok 4.5 charges $4 input and $12 output per million tokens once a prompt is over 200K tokens, instead of $2 input and $6 output; Grok 4.6 charges $4 input and $12 output per million tokens once a prompt is over 200K tokens, instead of $2 input and $6 output; Grok 4.7 charges $4 input and $12 output per million tokens once a prompt is over 200K tokens, instead of $2 input and $6 output. A 300K-token prompt with 2K output tokens on Grok 4.7 costs $1.22, against $0.61 at the standard rate.

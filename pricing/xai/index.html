Questions and answers

How much does the xAI Grok API cost?

xAI charges per million tokens, with separate prices for input and output. The cheapest is Grok Build 0.1 at $1 input and $2 output; the most expensive is Grok 4.7 at $2 input and $6 output. A typical request of 1,000 input and 500 output tokens costs between $0.002 and $0.005.

What is the cheapest Grok model?

Grok Build 0.1 (grok-build-0.1), at $1 per million input tokens and $2 per million output tokens.

Does xAI offer batch or cached pricing?

3 of the 7 models have a batch API price, processed within 24 hours at a lower rate. 7 models charge less for cached input that repeats across requests.

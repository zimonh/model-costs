OpenAI API pricing

As of October 28, 2026, the OpenAI API costs $0.05 to $10 per million input tokens and $0.4 to $50 per million output tokens, across 22 ChatGPT models. GPT-6 Luna costs $0.1 input and $0.5 output; GPT-4o mini costs $0.15 input and $0.6 output; GPT-5.4 nano costs $0.2 input and $1.25 output; GPT-5.4 mini costs $0.75 input and $4.5 output; GPT-6.1 Terra costs $1 input and $5 output; o3 costs $2 input and $8 output; GPT-6.1 Sol costs $2 input and $10 output; GPT-4o costs $2.5 input and $10 output. A typical request of 1,000 input and 500 output tokens costs $0.00025 on GPT-5 nano and $0.035 on GPT-6 Astra.

How batch, prompt caching and long context change the price

Batch API. All 22 priced ChatGPT models have a batch API price. Requests sent as a batch are processed within 24 hours and cost 50% less: GPT-4o drops from $2.5 input and $10 output to $1.25 and $5 per million tokens. See batch API pricing.

Prompt caching. All 22 priced ChatGPT models charge less for cached input, the part of a prompt that repeats across requests: typically 90% less. GPT-4o charges $1.25 per million cached input tokens instead of $2.5. Writing a prompt to the cache costs extra: 1.25× the input price for the standard cache (GPT-6 Astra: $12.5 per million tokens). The write pays for itself on the first request that reads the cache. See prompt caching pricing.

Long context. ChatGPT models accept 128K to 1.05M input tokens. Long prompts cost more on 10 models: GPT-6 Luna charges $0.2 input and $0.75 output per million tokens once a prompt is over 272K tokens, instead of $0.1 input and $0.5 output; GPT-5.6 Luna charges $0.4 input and $1.8 output per million tokens once a prompt is over 272K tokens, instead of $0.2 input and $1.2 output; GPT-6.1 Terra charges $2 input and $7.5 output per million tokens once a prompt is over 272K tokens, instead of $1 input and $5 output; GPT-6 Sol charges $4 input and $15 output per million tokens once a prompt is over 272K tokens, instead of $2 input and $10 output; GPT-6.1 Sol charges $4 input and $15 output per million tokens once a prompt is over 272K tokens, instead of $2 input and $10 output; GPT-5.6 Terra charges $4 input and $18 output per million tokens once a prompt is over 272K tokens, instead of $2 input and $12 output; GPT-5.4 charges $5 input and $22.5 output per million tokens once a prompt is over 272K tokens, instead of $2.5 input and $15 output; GPT-5.6 charges $8 input and $30 output per million tokens once a prompt is over 272K tokens, instead of $4 input and $20 output; GPT-5.5 charges $10 input and $45 output per million tokens once a prompt is over 272K tokens, instead of $5 input and $30 output; GPT-6 Astra charges $20 input and $75 output per million tokens once a prompt is over 272K tokens, instead of $10 input and $50 output. A 372K-token prompt with 2K output tokens on GPT-6 Astra costs $7.59, against $3.82 at the standard rate. The other 12 models list one price for their whole context window.

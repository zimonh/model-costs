Gemini API pricing (Google)

As of October 28, 2026, the Gemini API costs $0.1 to $2 per million input tokens and $0.4 to $12 per million output tokens, across 13 Gemini models. Gemini 3.5 Flash Lite costs $0.3 input and $2.5 output; Gemini 3.8 Flash costs $0.75 input and $3.75 output; Gemini Omni 1.1 Flash costs $1.5 input and $9 output; Gemini 4 Argon costs $2 input and $10 output; Gemini 3.1 Pro Preview costs $2 input and $12 output. A typical request of 1,000 input and 500 output tokens costs $0.0003 on Gemini 2.5 Flash Lite and $0.008 on Gemini 3.1 Pro Preview.

A coding agent step with 50K tokens of context and 2K output tokens costs $0.12 on Gemini 3.1 Pro Preview.

How batch, prompt caching and long context change the price

Batch API. 12 of the 13 priced Gemini models have a batch API price. Requests sent as a batch are processed within 24 hours and cost 50% less: Gemini 3.1 Pro Preview drops from $2 input and $12 output to $1 and $6 per million tokens. See batch API pricing.

Prompt caching. 12 of the 13 priced Gemini models charge less for cached input, the part of a prompt that repeats across requests: typically 90% less. Gemini 3.1 Pro Preview charges $0.2 per million cached input tokens instead of $2. See prompt caching pricing.

Long context. Every Gemini model accepts up to 1.05M input tokens. Long prompts cost more on 2 models: Gemini 2.5 Pro charges $2.5 input and $15 output per million tokens once a prompt is over 200K tokens, instead of $1.25 input and $10 output; Gemini 3.1 Pro Preview charges $4 input and $18 output per million tokens once a prompt is over 200K tokens, instead of $2 input and $12 output. A 300K-token prompt with 2K output tokens on Gemini 3.1 Pro Preview costs $1.24, against $0.62 at the standard rate. The other 11 models list one price for their whole context window.

Gemini API vs OpenAI and Claude

It depends on the model. The cheapest Gemini model, Gemini 2.5 Flash Lite, costs $0.0003 per typical request; the cheapest OpenAI model, GPT-5 nano, costs $0.00025. Gemini 3.1 Pro Preview ($0.008) is closest in price to GPT-5.6 Terra ($0.008): about the same.

Anthropic API pricing (Claude)

As of October 28, 2026, the Claude API costs $0.1 to $10 per million input tokens and $0.5 to $50 per million output tokens, across 16 Claude models. Claude Haiku 5.5 costs $0.1 input and $0.5 output; Claude Sonnet 5.5 costs $2 input and $10 output; Claude Opus 5.5 costs $4 input and $20 output; Claude Fable 5.1 costs $10 input and $50 output; Claude Mythos 5.1 costs $10 input and $50 output. A typical request of 1,000 input and 500 output tokens costs $0.00035 on Claude Haiku 5.5 and $0.035 on Claude Mythos 5.1.

How batch, prompt caching and long context change the price

Batch API. All 16 priced Claude models have a batch API price. Requests sent as a batch are processed within 24 hours and cost 50% less: Claude Mythos 5.1 drops from $10 input and $50 output to $5 and $25 per million tokens. See batch API pricing.

Prompt caching. All 16 priced Claude models charge less for cached input, the part of a prompt that repeats across requests: typically 90% less. Claude Mythos 5.1 charges $0.25 per million cached input tokens instead of $10. Writing a prompt to the cache costs extra: 1.25× the input price for the standard cache and 2× for the 1-hour cache (Claude Mythos 5.1: $12.5 and $20 per million tokens). The write pays for itself on the first request that reads the cache. See prompt caching pricing.

Long context. Claude models accept 200K to 1M input tokens. Long prompts cost more on one model: Claude Haiku 5.5 charges $0.5 input and $2.5 output per million tokens once a prompt is over 100K tokens, instead of $0.1 input and $0.5 output. A 200K-token prompt with 2K output tokens on Claude Haiku 5.5 costs $0.11, against $0.021 at the standard rate. The other 15 models list one price for their whole context window.

It depends on the model. The cheapest Claude model, Claude Haiku 5.5, costs $0.00035 per typical request; the cheapest OpenAI model, GPT-5 nano, costs $0.00025. Claude Mythos 5.1 ($0.035) is closest in price to GPT-6 Astra ($0.035): about the same.

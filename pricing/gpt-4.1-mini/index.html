Questions and answers

How much does the GPT-4.1 mini API cost?

OpenAI charges $0.4 per million input tokens and $1.6 per million output tokens for GPT-4.1 mini (gpt-4.1-mini), and $0.1 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.0012, or $0.0006 through the batch API.

Is there a cheaper way to use GPT-4.1 mini?

Yes. The OpenAI batch API runs requests within 24 hours for $0.2 per million input tokens and $0.8 per million output tokens. Prompt caching lowers the price of repeated input to $0.1 per million tokens.

What is the context window of GPT-4.1 mini?

GPT-4.1 mini accepts up to 1,047,576 input tokens, roughly 786,000 words of English, and writes up to 32,768 output tokens per response. Filling the whole context window once costs $0.42 in input tokens.

Is GPT-4.1 mini cheaper than Claude Haiku 4.5?

Yes. Claude Haiku 4.5 from Anthropic costs $1 input and $5 output per million tokens, so a typical request is $0.0035: 2.9× the price of GPT-4.1 mini.

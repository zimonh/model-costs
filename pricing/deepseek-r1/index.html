Questions and answers

How much does the DeepSeek R1 API cost?

DeepSeek charges $0.55 per million input tokens and $2.19 per million output tokens for DeepSeek R1 (deepseek-r1), and $0.14 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.00164.

Is there a cheaper way to use DeepSeek R1?

Prompt caching lowers the price of input that repeats across requests to $0.14 per million tokens.

What is the context window of DeepSeek R1?

DeepSeek R1 accepts up to 65,536 input tokens, roughly 49,000 words of English, and writes up to 8,192 output tokens per response. Filling the whole context window once costs $0.036 in input tokens.

Is DeepSeek R1 cheaper than GPT-5 mini?

No. GPT-5 mini from OpenAI costs $0.25 input and $2 output per million tokens, so a typical request is $0.00125: 1.3× cheaper than DeepSeek R1.

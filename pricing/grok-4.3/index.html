Questions and answers

How much does the Grok 4.3 API cost?

xAI charges $1.25 per million input tokens and $2.5 per million output tokens for Grok 4.3 (grok-4.3), and $0.2 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.0025, or $0.002 through the batch API.

Is there a cheaper way to use Grok 4.3?

Yes. The xAI batch API runs requests within 24 hours for $1 per million input tokens and $2 per million output tokens. Prompt caching lowers the price of repeated input to $0.2 per million tokens.

What is the context window of Grok 4.3?

Grok 4.3 accepts up to 1,000,000 input tokens, roughly 750,000 words of English, and writes up to 1,000,000 output tokens per response. Filling the whole context window once costs $1.25 in input tokens.

Is Grok 4.3 cheaper than GPT-5.4 mini?

Yes. GPT-5.4 mini from OpenAI costs $0.75 input and $4.5 output per million tokens, so a typical request is $0.003: 1.2× the price of Grok 4.3.

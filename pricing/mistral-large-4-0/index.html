Questions and answers

How much does the Mistral Large 4.0 API cost?

Mistral charges $1.36 per million input tokens and $4.18 per million output tokens for Mistral Large 4.0 (mistral-large-4-0), and $0.14 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.00345.

Is there a cheaper way to use Mistral Large 4.0?

Prompt caching lowers the price of input that repeats across requests to $0.14 per million tokens.

What is the context window of Mistral Large 4.0?

Mistral Large 4.0 accepts up to 1,048,576 input tokens, roughly 786,000 words of English, and writes up to 1,048,576 output tokens per response. Filling the whole context window once costs $1.43 in input tokens.

Is Mistral Large 4.0 cheaper than GPT-6.1 Terra?

They cost about the same. GPT-6.1 Terra from OpenAI costs $1 input and $5 output per million tokens, so a typical request is $0.0035: about the same price as Mistral Large 4.0.

gemini-4-argon API pricing

Google Gemini charges $2 per million input tokens and $10 per million output tokens for gemini-4-argon, and $0.1 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.007, or $0.0035 through the batch API.

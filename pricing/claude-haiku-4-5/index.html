Questions and answers

How much does the Claude Haiku 4.5 API cost?

Anthropic charges $1 per million input tokens and $5 per million output tokens for Claude Haiku 4.5 (claude-haiku-4-5), and $0.1 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.0035, or $0.00175 through the batch API.

Is there a cheaper way to use Claude Haiku 4.5?

Yes. The Anthropic batch API runs requests within 24 hours for $0.5 per million input tokens and $2.5 per million output tokens. Prompt caching lowers the price of repeated input to $0.1 per million tokens.

What is the context window of Claude Haiku 4.5?

Claude Haiku 4.5 accepts up to 200,000 input tokens, roughly 150,000 words of English, and writes up to 64,000 output tokens per response. Filling the whole context window once costs $0.20 in input tokens.

Is Claude Haiku 4.5 cheaper than GPT-6.1 Terra?

They cost about the same. GPT-6.1 Terra from OpenAI costs $1 input and $5 output per million tokens, so a typical request is $0.0035: about the same price as Claude Haiku 4.5.

claude-opus-5 API pricing

Anthropic charges $5 per million input tokens and $25 per million output tokens for claude-opus-5, and $0.5 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.0175, or $0.00875 through the batch API.

Questions and answers

How much does the Claude Opus 4.7 API cost?

Anthropic charges $5 per million input tokens and $25 per million output tokens for Claude Opus 4.7 (claude-opus-4-7), and $0.5 per million cached input tokens. A typical request of 1,000 input and 500 output tokens costs $0.0175, or $0.00875 through the batch API.

Is there a cheaper way to use Claude Opus 4.7?

Yes. The Anthropic batch API runs requests within 24 hours for $2.5 per million input tokens and $12.5 per million output tokens. Prompt caching lowers the price of repeated input to $0.5 per million tokens.

What is the context window of Claude Opus 4.7?

Claude Opus 4.7 accepts up to 1,000,000 input tokens, roughly 750,000 words of English, and writes up to 128,000 output tokens per response. Filling the whole context window once costs $5.00 in input tokens.

Is Claude Opus 4.7 cheaper than GPT-5.5?

Yes. GPT-5.5 from OpenAI costs $5 input and $30 output per million tokens, so a typical request is $0.02: 1.1× the price of Claude Opus 4.7.
